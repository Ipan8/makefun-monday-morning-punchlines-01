## The joke

> I set five alarms for Monday. The first four are decoys. The fifth is a witness.

80 characters — one joke about Monday mornings, inside the 200-character
limit. Short on purpose: the bounty tie-break rewards the shorter text
when scores are level.

## Why it should land

- **Really about Monday mornings:** five alarms is a Monday ritual — no
  other morning needs that many.
- **A punchline, not a complaint:** the joke never says Mondays are bad.
  The turn is the courtroom framing: decoys you snooze on purpose, then
  a witness that will testify you slept through them.
- **Surprise:** nobody's first thought about alarms is that four of them
  are decoys and the last one is there to give evidence.
- **Economy:** every word works. No setup is wasted, no cliché about
  coffee or hating Mondays.
- **Fresh:** alarms as decoys and a witness is not the tired Monday
  material everyone has heard — it treats oversleeping like a small
  courtroom drama instead of a complaint.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (creating the directory if
needed). The program is deterministic: no randomness, no network, no
clock. It also checks its own output before writing — the entry must be
1–200 characters and a single line.
